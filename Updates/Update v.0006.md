# Update v.0006 — ชี้ที่ node แล้วเห็นความสัมพันธ์ทันที

**วันที่:** 2026-09-15 · **ไฟล์ที่แก้:** `index.html` · `iis-knowladge.md`

## สิ่งที่ต้องได้
ชี้ที่ node แล้วเห็นเลยว่าอะไรเชื่อมกับอะไร คลิกถึงค่อยเปิด modal

## สิ่งที่แก้

### แยกเป็นสองจังหวะ
- **ชี้** — กล่องที่ไม่เกี่ยวจางลง เหลือ node นั้นกับเพื่อนบ้าน และ **ชื่อความสัมพันธ์ทุกเส้นโผล่พร้อมกัน**
- **คลิก** — เปิด modal อ่านคำอธิบายเต็ม เหมือนเดิม
- เพิ่มตัวแปร `hov` แยกจาก `sel` · `render()` ใช้ `hov || sel` ชี้อยู่ตรงไหนตัวนั้นมาก่อน
  เลิกชี้แล้วกลับไปแสดงตัวที่คลิกค้างไว้
- ผูก `focus` / `blur` ด้วย ไล่ Tab บนคีย์บอร์ดจึงได้ผลเหมือนชี้ด้วยเมาส์
- ชี้ที่เส้นยังอ่านทีละเส้นได้เหมือนเดิม ปล่อยแล้วกลับไปสถานะก่อนหน้า

### ป้ายชื่อต้องโชว์พร้อมกันได้
เดิมป้ายโผล่ทีละเส้นตอนชี้ที่เส้น จึงไม่เคยต้องกันป้ายชนป้าย พอเปลี่ยนมาโชว์ทั้งชุดตอนชี้ที่ node
ต้องเพิ่มเงื่อนไขว่า **ป้ายของเส้นที่ออกจาก node เดียวกันต้องไม่ทับกันเอง** แล้ววางตำแหน่งใหม่ทั้ง 76 เส้น

ระหว่างทางเจอสองเรื่อง
- ระยะเผื่อขอบกล่องเดิม 2px น้อยเกินไป การปัดพิกัดเป็นจำนวนเต็มทำให้ 4 ป้ายเฉี่ยวกล่อง ขยับเป็น 5px
- เส้นสั้นระหว่างกล่องที่ติดกัน (`root application` → `root virtual dir`) ไม่มีที่ว่างตามแนวเส้นเลย
  เพิ่มการค้นเป็นวงรอบจุดกึ่งกลางเป็นทางสำรอง
