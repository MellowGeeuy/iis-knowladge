# Update v.0002 — panel ของ KG อธิบายเป็นภาษาคน · สารบัญหุบได้

**วันที่:** 2026-09-15 · **ไฟล์ที่แก้:** `index.html`

## 1 · panel ของ KG ต้องบอกว่า node คืออะไร และเกี่ยวกับตัวอื่นยังไง

เดิม panel แสดงแค่ชื่อ predicate ลอย ๆ กดที่ W3SVC แล้วไม่รู้ว่ามันคืออะไร
และไม่รู้ว่าเกี่ยวกับ applicationHost.config หรือ WAS อย่างไร

- เพิ่ม `ABOUT` — คำอธิบายของ node ทั้ง 54 ตัว ขึ้นเป็นบรรทัดแรก รูปแบบ `<ชื่อ> คือ …`
- เพิ่ม `WHY` — คำอธิบายรายเส้นทั้ง 65 เส้น คีย์ `subject>object` บอกว่าเส้นนั้นเกี่ยวกันอย่างไร
- เพิ่ม `VERB` — คำกริยาไทยของ predicate ทั้ง 55 ตัว ใช้ขึ้นต้นประโยคแทนชื่ออังกฤษ
- แยกความสัมพันธ์เป็นสองกลุ่ม `<node> ทำอะไรกับสิ่งอื่น` และ `สิ่งอื่นทำอะไรกับ <node>`
  แทนการปนกันแล้วใช้ลูกศร → ← ให้เดาเอง
- เลิกใช้ศัพท์กราฟในป้ายกำกับ · `id` เอาออก · `label` → `หมวด` · `degree` → `เชื่อมกับ N สิ่ง`
  · `relationship · ออก · เข้า` บนหัว panel → `หมวด X · ส่วนที่ Y`
- ชื่อ predicate ยังอยู่ แต่ลดเป็นป้ายเล็กท้ายบรรทัด เผื่อเอาไปค้นต่อ

**ผลลัพธ์เมื่อกดที่ W3SVC**
```
W3SVC                                    หมวด IIS · ส่วนที่ 01
W3SVC คือ บริการที่คอยตั้งค่าให้ HTTP.sys และแจ้ง WAS เมื่อมี request เข้าคิว
[หมวด IIS] [อยู่ในส่วนที่ 01] [เชื่อมกับ 2 สิ่ง]

W3SVC ทำอะไรกับสิ่งอื่น  2
  อ่านค่าจาก applicationHost.config          READS
  W3SVC อ่านค่า site และ binding ทั้งหมดจากไฟล์นี้ แล้วนำไปตั้งค่าให้ HTTP.sys ว่าต้องรับฟัง port ใดบ้าง

  แจ้งเหตุไปยัง WAS                          NOTIFIES
  เมื่อมี request เข้าคิวแต่ยังไม่มี worker process รองรับ W3SVC จะแจ้ง WAS ให้จัดการ
```

**ที่มาของเนื้อหา** — ทุกบรรทัดถอดจาก `iis-knowladge.md` ส่วนใหญ่มาจากตารางอภิธานศัพท์
(บรรทัด 1016 เป็นต้นไป) ที่เหลือมาจากเนื้อความในส่วนที่เกี่ยวข้อง เช่น `autoDeploy` บรรทัด 791 ·
`server.proxy` บรรทัด 910 · `httperr` บรรทัด 111 · นิยาม Tomcat บรรทัด 751 ไม่มีบรรทัดใดเขียนขึ้นเอง

## 2 · สารบัญหุบได้ เนื้อหาจะได้กินพื้นที่เต็ม

- ปุ่ม `«` มุมบนขวาของแถบซ้าย กดแล้วแถบซ้ายหาย
- หุบแล้วแถบบนโผล่ขึ้นมาพร้อมปุ่ม `» สารบัญ` สำหรับเปิดกลับ · ปุ่มนี้อยู่ใน flow ปกติ
  ไม่ใช่ปุ่มลอย เพราะปุ่มลอยที่ `left: 0` จะไปทับ breakout บนจอกว้าง 901–1100px
- เพิ่ม token `--wide-open: 1264px` (= `--wide` 1000 + `--side` 264) `.shell.nav-off` override `--wide`
  ด้วยค่านี้ เนื้อหาจึงกินพื้นที่ที่แถบซ้ายเคยอยู่จริง ไม่ใช่แค่ถูกจัดกึ่งกลางใหม่
- จอแคบ (≤900px) ไม่กระทบ ยังใช้ drawer กับปุ่มสารบัญเดิม ปุ่มหุบถูกซ่อน
