# เจาะโครงสร้าง IIS

เอกสารอธิบายกลไกการทำงานภายในของ Internet Information Services (IIS)
และขั้นตอนการกำหนดค่าเพื่อนำเว็บแอปพลิเคชันขึ้นให้บริการบน Windows Server

**เปิดอ่าน:** https://mellowgeeuy.github.io/iis-knowladge/

## ขอบเขต

เอกสารนี้อธิบาย **ชั้น IIS** คือส่วนที่รับ request จากผู้ใช้
ตัดสินใจว่าจะตอบด้วยไฟล์บนดิสก์หรือส่งต่อไปยังเซิร์ฟเวอร์อื่น และบันทึกผลลัพธ์ไว้

ส่วนที่ 01 ถึง 09 เรียกปลายทางว่า *เซิร์ฟเวอร์ปลายทาง* แบบกลาง ๆ
จึงใช้ได้โดยไม่ขึ้นกับว่าแอปพลิเคชันเบื้องหลังพัฒนาด้วยเทคโนโลยีใด
ส่วนที่ 10 และ 11 จึงค่อยลงรายละเอียดเฉพาะกรณีที่ปลายทางคือ **Spring Boot บน Apache Tomcat** และหน้าบ้านเป็น **React**
โดยจำกัดเฉพาะค่าที่ต้องตั้งให้สอดคล้องกับ IIS

สิ่งที่อยู่นอกขอบเขต ได้แก่ การพัฒนาแอปพลิเคชัน การออกแบบฐานข้อมูล
และกติกาทางธุรกิจของระบบ

## เนื้อหา

เอกสารแบ่งเป็น 13 หน้า แสดงทีละส่วน

| ส่วน | หัวข้อ |
|---|---|
| — | ภาพรวมและขอบเขต |
| 01 | องค์ประกอบภายในของ IIS |
| 02 | หน่วยการจัดการทั้งสี่ |
| 03 | หน้าที่สองประการของ IIS |
| 04 | การติดตั้งองค์ประกอบที่จำเป็น |
| 05 | การสร้าง Application Pool และ Site |
| 06 | การกำหนดกฎใน web.config |
| 07 | การส่งข้อมูลผู้เรียกไปยังเซิร์ฟเวอร์ปลายทาง |
| 08 | การกำหนด HTTPS และ Binding |
| 09 | การตรวจสอบและวิเคราะห์ปัญหา |
| 10 | การเตรียม Spring Boot ให้ทำงานกับ IIS |
| 11 | การเตรียม React ให้ทำงานกับ IIS |
| — | แหล่งอ้างอิง |

ภายในมีแผนภาพ SVG 11 รูป ครอบคลุมทุกส่วนของเอกสาร โดยเส้นที่แทนการไหลของ request
เคลื่อนไหวตามทิศทางจริง และหยุดอัตโนมัติเมื่อผู้อ่านตั้งค่าลดการเคลื่อนไหวในระบบปฏิบัติการ


## แหล่งอ้างอิง

เนื้อหาทุกส่วนอ้างอิงจากเอกสารทางการของ Microsoft, Spring Boot, Apache Tomcat, Vite และ React Router ที่เปิดอ่านเนื้อหาเต็มแล้ว
รวม 25 รายการ แสดงไว้ในหน้าสุดท้ายของเอกสาร

ชื่อ site พาธของไฟล์ หมายเลขพอร์ต และพาธปลายทางทั้งหมดเป็นค่าตัวอย่างที่กำหนดขึ้น
มิใช่ค่าที่ตรวจวัดหรือดึงมาจากระบบจริง

## โครงสร้างไฟล์

```
.
├─ index.html    เอกสารทั้งฉบับ ไฟล์เดียวจบ ไม่มี dependency ภายนอกนอกจากฟอนต์
├─ .nojekyll     ปิดการประมวลผลด้วย Jekyll ของ GitHub Pages
└─ README.md
```

`index.html` ฝังทั้ง CSS และ JavaScript ไว้ในไฟล์เดียว
โหลดเฉพาะฟอนต์จาก Google Fonts ได้แก่ Anuphan, Kanit และ Source Code Pro

## การเปิดใช้งาน GitHub Pages

1. เข้าไปที่ **Settings → Pages** ของ repository
2. ที่ **Source** เลือก **Deploy from a branch**
3. เลือก branch `main` และโฟลเดอร์ `/ (root)` แล้วกด **Save**
4. รอสักครู่ เว็บจะเผยแพร่ที่ `https://mellowgeeuy.github.io/iis-knowladge/`

และปรับการแสดงผลได้ถึงความกว้างระดับโทรศัพท์มือถือ
