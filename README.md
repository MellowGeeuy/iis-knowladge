# เจาะโครงสร้าง IIS

เอกสารความรู้สำหรับทีมพัฒนา อธิบายว่า IIS, Spring Boot, Apache Tomcat 11 และ React
แต่ละตัวคืออะไร ทำงานอย่างไร และเมื่อนำมาประกอบกันแล้วเป็นระบบเดียวได้อย่างไร

**เปิดอ่าน:** https://mellowgeeuy.github.io/iis-knowladge/

## ขอบเขต

เอกสารนี้อธิบาย **ชั้น deployment** คือส่วนที่รับ HTTP request จากเบราว์เซอร์
ตัดสินใจว่าจะตอบด้วยไฟล์ static บนดิสก์หรือ proxy ต่อไปยัง backend และบันทึก log ไว้

ส่วนที่ 01 ถึง 09 เรียกปลายทางว่า *upstream server* แบบกลาง ๆ
จึงใช้ได้โดยไม่ขึ้นกับว่า backend พัฒนาด้วยเทคโนโลยีใด
ส่วนที่ 10 ถึง 13 จึงค่อยลงรายละเอียดเฉพาะกรณีที่ backend คือ **Spring Boot บน Apache Tomcat 11**
และ frontend เป็น **React** ที่ build ด้วย Vite
โดยจำกัดเฉพาะค่าที่ต้องตั้งให้สอดคล้องกันระหว่างสามชั้น

เหตุที่ใช้ IIS คือระบบรันบน **Windows Server** ซึ่งมี IIS ติดมากับระบบปฏิบัติการอยู่แล้ว
มิใช่ข้อบังคับขององค์กร

สิ่งที่อยู่นอกขอบเขต ได้แก่ business logic ของแอปพลิเคชัน การออกแบบฐานข้อมูล
และการเขียนโค้ดภายในแต่ละเฟรมเวิร์ก

## แหล่งอ้างอิง

เนื้อหาทุกส่วนอ้างอิงจากเอกสารทางการของ Microsoft, Spring Boot, Apache Tomcat, Vite และ React Router ที่เปิดอ่านเนื้อหาเต็มแล้ว
รวม 32 รายการ แสดงไว้ในหน้าสุดท้ายของเอกสาร

ชื่อ site พาธของไฟล์ หมายเลขพอร์ต และพาธปลายทางทั้งหมดเป็นค่าตัวอย่างที่กำหนดขึ้น
มิใช่ค่าที่ตรวจวัดหรือดึงมาจากระบบจริง

## โครงสร้างไฟล์

```
.
├─ index.html    เอกสารทั้งฉบับ ไฟล์เดียวจบ ไม่มี dependency ภายนอกนอกจากฟอนต์
├─ .nojekyll     ปิดการประมวลผลด้วย Jekyll ของ GitHub Pages
└─ README.md
```

`index.html` ฝังทั้ง CSS และ JavaScript ไว้ในไฟล์เดียว
โหลดเฉพาะฟอนต์จาก Google Fonts ได้แก่ Anuphan, Kanit และ Source Code Pro

## การเปิดใช้งาน GitHub Pages

1. เข้าไปที่ **Settings → Pages** ของ repository
2. ที่ **Source** เลือก **Deploy from a branch**
3. เลือก branch `main` และโฟลเดอร์ `/ (root)` แล้วกด **Save**
4. รอสักครู่ เว็บจะเผยแพร่ที่ `https://mellowgeeuy.github.io/iis-knowladge/`
